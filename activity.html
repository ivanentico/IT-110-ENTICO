5. HTML DOM

The HTML DOM represents a web page as a tree of elements. Each element can have parent and child elements.

DOM Structure

  • HTML is the root element.
  • Body is a child of HTML.
  • Main is a child of Body.
  • Sections are children of Main.
  • Headings and paragraphs are children of sections.

Parent and Child Relationship

The body element is the parent of the main element because main is placed inside body.

The main element is the parent of the section elements inside it.

Within each section, elements such as h2, p, img, and ul become child elements of the section.

The ul element is the parent of its li elements.
